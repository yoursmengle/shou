# Proposal

## Why

Windows x64 的智能清理能够扫描和选择项目，但公开执行开关固定关闭，导致合格项目无法通过“永久删除”执行。本机 0.21.0 的实际扫描同时记录文件占用和局部超时，界面的通用错误提示无法说明这些缺口与执行不可用的区别。

## What Changes

- 为原生 Windows 11 x64 的规则清理接通已有计划、当前范围确认、实时复核及逐项日志链路；原生生成夹具验证通过后开放对应能力。
- 保持部分扫描的真实覆盖信息，允许独立完整、无阻断的所选目标执行；不完整、只读、受保护、活跃或证据变化的目标仍拒绝。
- 为文件共享冲突、扫描时间及条目／深度预算提供准确的中英文说明，明确部分扫描仍可处理合格项目，并保留重新扫描单个位置的入口。
- 校正单位置规则扫描的完成性显示，避免把已完成的规则目标扫描误标为未完成的全树扫描。
- 将规则清理能力与空间删除、隐私删除隔离，防止共享开关扩大本次权限；同步 CLI 能力发现和打包能力元数据。
- 添加状态、错误映射和原生临时夹具回归，更新中英文合同与跨端证据。

## Capabilities

### New Capabilities

- `windows-rule-cleanup`: Windows 规则清理的部分覆盖呈现、合格目标选择、受限平台能力及当前确认执行。

### Modified Capabilities

无。当前 OpenSpec 主规范尚无已有能力。

## Impact

涉及 Windows App、Presentation、Platform、CLI 的规则清理入口及相关测试，共享文案及其确定性生成资源，Windows 打包能力回执，中英文日常清理／安全／平台说明与 SYNC.md。沿用现有扫描预算和文件共享保护，不终止用户进程、不修改 ACL、不将真实个人数据作为删除回归夹具，不增加依赖，不创建提交或发行版。
